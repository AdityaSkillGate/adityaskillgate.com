🔌 Google Apps Script API URL
Enter the deployed URL of your Google Apps Script to connect the website to Google Sheets database.
This URL connects the frontend to your Google Sheets. See setup instructions below.
📋 Setup Instructions
Follow these steps to connect the website to Google Sheets.
1
Open Google Apps Script

Go to script.google.com and open the ASG project.

2
Deploy as Web App

Click Deploy → New Deployment → Web App. Set access to "Anyone".

3
Copy the URL

Copy the Web App URL and paste it above, then save.

4
Update js/api.js

Also update the API_BASE_URL constant in js/api.js with the same URL.
